# چک‌لیست انتشار «محله‌ی ما» در کافه‌بازار و مایکت

بازی کامل است و هر بار که کد پوش می‌شود، GitHub نسخه‌ی اندروید را می‌سازد. فقط این کارها
از دست من (Claude) برنمی‌آید، چون حساب و هویت شما لازم است:

## ۱. امتحان روی گوشی (۵ دقیقه)
1. روی گوشی صفحه‌ی **Releases** مخزن را باز کنید و نسخه‌ی `android-latest` را بزنید.
2. فایل `Mahalle.apk` (نسخه‌ی بازار) را دانلود و نصب کنید (اجازه‌ی نصب از این منبع را بدهید).
   فایل `Mahalle-myket.apk` همان بازی برای مایکت است.
3. این نسخه با کلید آزمایشی امضا شده: برای بازی کردن عالی است، **برای بازار نه**.

## ۲. حساب توسعه‌دهنده‌ی بازار
1. در [pishkhan.cafebazaar.ir](https://pishkhan.cafebazaar.ir) ثبت‌نام کنید (هویت و حساب بانکی).
2. یک برنامه‌ی جدید با نام بسته‌ی `com.admeve.mahalle` بسازید.
3. در بخش «پرداخت درون‌برنامه‌ای» این محصولات **مصرفی** را بسازید:

| شناسه (SKU) | محتوا | قیمت پیشنهادی |
|---|---|---|
| `starter_pack` | ۱۲۰ الماس + ۱۵۰ انرژی + صندوقچه‌ی طلایی (یک‌بار) | ۴۹٬۰۰۰ تومان |
| `gems_small` | ۶۰ الماس | ۲۹٬۰۰۰ تومان |
| `gems_medium` | ۱۶۰ الماس | ۶۹٬۰۰۰ تومان |
| `gems_large` | ۴۲۰ الماس | ۱۴۹٬۰۰۰ تومان |
| `gems_huge` | ۱۰۰۰ الماس | ۲۹۹٬۰۰۰ تومان |
| `offer_energy` | ۲۵۰ انرژی + ۲۰ الماس (وقتی انرژی تموم شده) | ۱۹٬۰۰۰ تومان |
| `offer_chapter` | ۸۰ الماس + ۱۰۰ انرژی + صندوقچه‌ی طلایی (۲۴ ساعت بعد از هر قسمت) | ۴۹٬۰۰۰ تومان |
| `piggy_bank` | شکستن قلک: هر چی الماس توشه (۶۰ تا ۱۵۰) | ۳۹٬۰۰۰ تومان |
| `pass_premium` | «مسیر طلایی» همین ماه (جایزه‌های طلایی ۳۰ مرحله) | ۷۹٬۰۰۰ تومان |

قیمت‌ها را هر وقت خواستید در پیشخوان عوض کنید؛ بازی قیمت را از بازار می‌خواند.

4. **کلید RSA** برنامه را از همان بخش کپی کنید.

## ۲ب. مایکت (اختیاری ولی توصیه‌شده: دومین فروشگاه ایران)
1. در [developer.myket.ir](https://developer.myket.ir) ثبت‌نام کنید و برنامه‌ای با همان نام بسته‌ی
   `com.admeve.mahalle` بسازید.
2. همان محصولات (همان شناسه‌ها) را در بخش پرداخت درون‌برنامه‌ای بسازید.
3. **کلید RSA مایکت** را کپی کنید.

## ۳. تپسل (اختیاری، برای ویدیوی جایزه‌دار)
در [tapsell.ir](https://tapsell.ir) یک برنامه و یک «تبلیغ جایزه‌دار (Rewarded Video)» بسازید و
«کلید برنامه» و «شناسه‌ی تبلیغ‌گاه» را بردارید. بدون این‌ها هم بازی کامل کار می‌کند.

## ۴. کلید امضا (فقط یک بار، و برای همیشه نگهش دارید!)
بازار فقط آپدیت‌هایی را قبول می‌کند که با **همان کلید** امضا شده باشند. اگر گمش کنید، دیگر
نمی‌توانید بازی را آپدیت کنید.

```bash
keytool -genkeypair -v -keystore mahalle-release.jks -alias mahalle -keyalg RSA -keysize 4096 -validity 36500
base64 -w0 mahalle-release.jks > mahalle-release.jks.b64
```

از فایل `mahalle-release.jks` و رمزش چند نسخه‌ی پشتیبان امن نگه دارید.

## ۵. رازها (Secrets) در گیت‌هاب
مخزن → **Settings → Secrets and variables → Actions → New repository secret**:

| نام | مقدار |
|---|---|
| `MAHALLE_KEYSTORE_BASE64` | محتوای فایل `mahalle-release.jks.b64` |
| `MAHALLE_KEYSTORE_PASSWORD` | رمز keystore |
| `MAHALLE_KEY_ALIAS` | `mahalle` |
| `MAHALLE_KEY_PASSWORD` | رمز کلید |
| `BAZAAR_RSA_KEY` | کلید RSA بازار از مرحله‌ی ۲ |
| `MYKET_RSA_KEY` | کلید RSA مایکت از مرحله‌ی ۲ب (اختیاری) |
| `TAPSELL_APP_KEY` | کلید تپسل (اختیاری) |
| `TAPSELL_REWARDED_ZONE` | شناسه‌ی تبلیغ‌گاه (اختیاری) |

بعد در تب **Actions** گردش‌کار «Build game» را دوباره اجرا کنید (Run workflow).

## ۶. بارگذاری در بازار و مایکت
1. `Mahalle.apk` جدید (امضاشده با کلید خودتان) را از Releases بردارید و در پیشخوان بازار آپلود
   کنید. `Mahalle-myket.apk` را در پنل مایکت آپلود کنید (همان کلید امضا، نسخه‌ی مخصوص مایکت).
2. متن‌ها: [`docs/store-listing.md`](store-listing.md) (نام، توضیح کوتاه، توضیح کامل).
3. تصاویر: پوشه‌ی [`docs/screenshots/`](screenshots/) (۸ تصویر ۱۰۸۰×۱۹۲۰ با کپشن).
4. آیکون: `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` (یا `public/icon.svg`).
5. رده‌ی سنی: ۳+. دسته: بازی › تفننی.

## بعد از انتشار
- نظرات کاربران را بخوانید. بیشترین تأثیر را **امتیاز بازار** دارد و بازی بعد از قسمت اول
  خودش از بازیکن می‌خواهد امتیاز بدهد.
- هجده فصل (۹۰ قسمت) در نسخه‌ی اول هست. فصل نوزدهم (گلاب‌گیری قمصر) را می‌شود به‌صورت آپدیت
  منتشر کرد؛ هر آپدیت، بازی را دوباره در بازار دیده‌شدنی‌تر می‌کند.
